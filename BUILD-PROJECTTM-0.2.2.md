# ProjectTM 0.2.2 — video format compatibility and audio gain

## Purpose

ProjectTM 0.2.1 proved that the clean four-buffer Switch audio driver was
stable, but hardware produced no visible game image. The Vulkan presenter was
healthy while every captured guest output remained black. Comparing the same
boot interval with the known-good V4R1 run isolated the persistent difference:

- V4R1: `resolve_fmt=12->6`
- 0.2.1: `resolve_fmt=3->6`

Xenos formats 3 (`k_2_10_10_10_FLOAT`) and 12
(`k_2_10_10_10_FLOAT_AS_16_16_16_16`) share the same underlying storage
format, but the clean NVK renderer followed the format-3 view path that was
black on hardware.

## Changes

- Normalize RB_COLOR_INFO format 3 to its storage-compatible format-12 view at
  Vulkan register ingestion. This keeps render-target ownership, drawing and
  resolve interpretation coherent instead of patching only the final copy.
- Increase genuine game-audio output makeup gain from 1.75x to 2.5x. Existing
  saturation remains in place, so amplified samples cannot overflow int16.
- Retain four Switch audio wave buffers and the 584-byte
  `SwitchAudioDriver` ABI established by 0.2.1.
- Bump build identity, logs and artifact names to 0.2.2.

## Verification

- Full clean Switch/NVK/Vulkan build completed successfully.
- All 85 generated GTA IV units were compiled and linked.
- Import coverage: 0 missing of 246.
- Linked `SwitchAudioSystem::CreateDriver` allocates `0x248` (584) bytes.
- Linked `VulkanCommandProcessor::WriteRegister` contains the format-3 to
  format-12 normalization before the base register write.
- NRO size: 70,236,357 bytes.
- SHA-256: `476343F4F79615F404830EBB138EE7A95F83CC9337E26B7EFA0EE75D3928F771`.

## Hardware expectations

- `FrameFlow` should report `resolve_fmt=12->6` from the affected color target.
- Guest-output captures should become non-black and restore logos/slideshow.
- Game audio should be substantially louder than 0.2.1 while remaining
  generated by GTA IV's real XMA/audio path.

This build does not claim to eliminate every occasional audio underrun; it
targets the proven black-video format mismatch and requested output level.
